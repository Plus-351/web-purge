¿Qué hace Web Purge?

Web Purge es una herramienta ligera de privacidad que borra datos del navegador asociados a sitios concretos o grupos de dominios (trackers, anuncios, redes sociales, etc.). Usa el popup para una limpieza rápida del sitio actual o administra categorías y dominios personalizados desde la página de Opciones.[page:1]

  • Limpieza con un clic para el dominio de la pestaña activa.[page:1]
  • Categorías predefinidas de trackers, anuncios, redes sociales y más.[page:1]
  • Dominios personalizados para adaptar la limpieza a tu flujo de trabajo.[page:1]
  • Estado parcial/indeterminado cuando solo parte de una categoría está activa.[page:1]
  • Interfaz localizable con soporte para múltiples idiomas.[page:1]

¿Cómo funciona?

La extensión utiliza las APIs del navegador para limpiar almacenamiento específico de los sitios que selecciones (cookies, localStorage, caché y otros datos de sitio). Las preferencias se guardan en el almacenamiento local del navegador y se respetan durante las actualizaciones.[page:1]

Privacidad primero

Borrar por completo el historial del navegador suele ser la reacción instintiva cuando alguien quiere proteger su privacidad, pero ese comportamiento puede resultar sospechoso y, aun así, no elimina todos los datos temporales ni la caché.[page:1]

Web Purge funciona íntegramente del lado del cliente y te permite eliminar cookies, almacenamiento local, caché y otros datos únicamente para los dominios que configures y dentro del período de tiempo que definas, ofreciendo una limpieza profunda donde importa sin vaciar todo tu historial.[page:1]

No recopilamos ni vendemos tu información personal. Para más detalles, consulta la Política de privacidad.[page:1]

What does Web Purge do?

Web Purge is a lightweight privacy tool that lets you remove all browser data associated with specific websites or predefined categories (trackers, ads, social networks, etc.). Use the popup for one‑click cleanup of the current site, or manage categories and custom domains from the Options page.[page:1]

  • One‑click cleanup for the active tab's domain.[page:1]
  • Predefined category lists plus custom user domains.[page:1]
  • New custom domains are created enabled by default.[page:1]
  • Categories reflect partial/complete selection (indeterminate state).[page:1]
  • Localizable UI with multiple language support.[page:1]

How does it work?

The extension uses browser APIs to clear site‑specific storage (cookies, localStorage, cache, etc.) for selected origins. Settings are stored locally in browser storage and are preserved across updates.[page:1]

No accounts No telemetry No external servers

Privacy first

Completely clearing your browser history is often the instinctive reaction when you want privacy, but that behavior can look suspicious and still leaves temporary data and cache behind.[page:1]

Web Purge runs fully client‑side and lets you remove cookies, local storage, cache and other data only for the domains you configure and within the time range you select, offering deep cleanup where it matters without erasing your entire history.[page:1]

We do not collect or sell your personal information. For full details, see the Privacy Policy.[page:1]
