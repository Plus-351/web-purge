Web Purge

Quickly remove cookies, local storage, cache and other site data for the current domain or groups of domains.

Web Purge is a lightweight privacy tool that lets you remove all browser data associated with specific websites or predefined categories (trackers, ads, social networks, etc.). Use the popup for one‑click cleanup of the current site, or manage categories and custom domains from the Options page. All operations run locally in your browser — no external servers.

Key features

  • One‑click cleanup for the active tab
  • Predefined category lists plus user custom domains
  • Add custom domains (created enabled by default)
  • Categories reflect partial/complete selection (indeterminate state)
  • Localizable UI (multiple languages supported)
  • Safe defaults and merge behavior on updates (user preferences preserved)

How it works

The extension uses browser APIs to clear site-specific storage (cookies, localStorage, cache, etc.) for selected origins. Settings are stored locally in browser storage and can be managed from the Options page.

Privacy

Web Purge runs fully client-side and does not send your data to external services. Permissions are limited to what's necessary to read settings and clear local site data. See the privacy page for details.
