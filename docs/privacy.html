Privacy notice — Web Purge

Effective Date: Jan 1, 2026

Web Purge is a small browser extension that helps remove browsing data (history, cookies, localStorage, cache) associated with configured target sites. It stores only minimal configuration and backup data in chrome.storage (sync and/or local) to remember which categories and domains you have enabled and to support non-destructive defaults updates.

What we store

  • Configuration: your selected categories and per-domain enabled flags (in chrome.storage.sync).
  • Backups & metadata: previous configs and defaults metadata (in chrome.storage.local).
  • Debug markers: temporary keys used only for development.

What we don't collect

Web Purge does not send your browsing data to any remote server. It only performs cleanup actions locally within your browser. Remote defaults (published JSON) are fetched only to update the shipped list of default domains; these files contain only domain lists and version metadata.

Data retention

Sync configuration remains in your browser profile and (optionally) across your signed-in Chrome profiles if you use chrome.storage.sync. Local backups are kept in chrome.storage.local and rotated (old backups removed) by the extension.

Questions

Open an issue on the project repository or contact the maintainer if you have privacy concerns.
