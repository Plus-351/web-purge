# Security Policy for Web Purge

## Reporting Security Vulnerabilities

If you discover a security vulnerability in this extension, please report it to us as soon as possible. We take security seriously and will respond promptly to any reports.

### Contact Information

Please send your reports to the following email address:

[security@webpurge.com](mailto:security@webpurge.com)

### Guidelines for Reporting

When reporting a vulnerability, please include the following information:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- Any relevant screenshots or logs
- Your contact information (optional, but helpful for follow-up)

## Security Practices

We follow best practices to ensure the security of our users:

- **No Data Collection**: Web Purge does not collect any personal data or browsing history.
- **Local Execution**: All operations are performed locally within the user's browser.
- **Regular Updates**: We regularly update the extension to address any identified vulnerabilities and improve security.

## Responsible Disclosure

We appreciate your help in keeping Web Purge secure. We ask that you do not disclose any vulnerabilities publicly until we have had a chance to address them.

Thank you for your cooperation!
